# Fuentes locales

League Gothic Regular y Barlow Condensed (pesos 500 y 600), distribuidas bajo SIL Open Font License 1.1. Los archivos de licencia acompañan las fuentes.

Origen: repositorio google/fonts, familias ofl/leaguegothic y ofl/barlowcondensed. Se sirven desde la app para que la interfaz funcione sin peticiones a servicios de tipografía.
